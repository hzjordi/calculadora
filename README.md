# 🧮 Calculadora Científica Web Accesible

Aplicación web de calculadora científica interactiva, ligera y funcional, **adaptada especialmente para personas con baja visión**, desarrollada y desplegada directamente a través de **GitHub Pages**.

🌐 **Pruébala en vivo:** [https://hzjordi.github.io/calculadora/](https://hzjordi.github.io/calculadora/)

---

## 📋 Características

* **Accesibilidad para baja visión:** Diseño visual pensado para facilitar la lectura e identificación rápida de teclas y resultados.
* **Modos de contraste personalizables:**
  * **Modo claro clásico:** Fondo blanco con símbolos en negro.
  * **Alto contraste (amarillo):** Fondo negro con símbolos en amarillo.
  * **Modo oscuro de alto contraste:** Fondo negro con símbolos en blanco.
* **Operaciones científicas:** Soporte para funciones matemáticas avanzadas (trigonometría, logaritmos, potencias, raíces, constantes matemáticas y más).
* **Interfaz adaptable (Responsive):** Visualización clara y cómoda tanto en ordenadores como en dispositivos móviles o tabletas.
* **Ejecución instantánea:** Funciona directamente en el navegador sin necesidad de dependencias externas (todo contenido en un único archivo).

## 🛠️ Tecnologías utilizadas

* **HTML5**
* **CSS3**
* **JavaScript**

## 🚀 Uso en local

Si deseas descargar o probar el proyecto en tu propio equipo:

1. Clona este repositorio:
   ```bash
   git clone https://github.com/hzjordi/calculadora.git
   ```
2. Entra en la carpeta del proyecto:
   ```bash
   cd calculadora
   ```
3. Abre el archivo `index.html` directamente en tu navegador web.
