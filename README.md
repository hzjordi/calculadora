# 🧮 Calculadora Científica Web

Aplicación web de calculadora científica interactiva, ligera y funcional, desarrollada y desplegada directamente a través de **GitHub Pages**.

🌐 **Pruébala en vivo:** [https://hzjordi.github.io/calculadora/](https://hzjordi.github.io/calculadora/)

---

## 📋 Características

* **Operaciones científicas avanzadas:** Funciones trigonométricas (seno, coseno, tangente), logaritmos, potencias, raíces cuadradas y constantes matemáticas (π, e).
* **Interfaz intuitiva:** Diseño limpio, organizado y adaptable a dispositivos móviles y de escritorio.
* **Ligera y autocontenida:** Ejecución instantánea en el navegador sin necesidad de librerías o dependencias externas (todo integrado en `index.html`).

## 🛠️ Tecnologías utilizadas

* **HTML5**
* **CSS3**
* **JavaScript**

## 🚀 Uso en local

Si deseas descargar o probar el proyecto en tu propio equipo:

1. Clona este repositorio:
   ```bash
   git clone https://github.com/hzjordi/calculadora.git
   ```
2. Entra en la carpeta del proyecto:
   ```bash
   cd calculadora
   ```
3. Abre el archivo `index.html` directamente en tu navegador web.
